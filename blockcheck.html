#판정요청 거래처사유매칭 거래처
판정 기준
  • 로컬 (채널매핑 담당 부서 기준) — 다른 CSO 코드 있음 → 불가 / 한올 담당자(영업부·MS팀 등) 있음 → 불가 / 대웅 담당자(DW·DA·DB·폴라리스)만 → 협의필요 / 영업기획팀·영업관리팀만 담당(비활성처) → 가능 / 담당 없음(비거래처) → 가능
  • 병원 (품목을 함께 입력) — 그 품목의 최근 6개월 매출(DW·HA병원) 있음 → 불가 / PRM 블럭신청 후 6개월 이내(신규 블럭 유예) → 매출이 안 보여도 불가(OCS 2개월 지연) / CRM(일일보고) 진행 중: DC접수 이상 업체가 있으면 불가 / 110대 병원은 DC접수 전 복수오픈 3곳 미만이면 가능(협의필요)·3곳이면 불가 / 110대가 아닌 병원은 진행 중 업체가 있으면 불가(복수오픈 없음) / 그 외 매출 없음 → 가능. 단 MS팀·한올영업부·대웅영업부가 담당하거나 다른 CSO 코드·6개월 지난 PRM 신청이 있으면 가능(협의필요). 품목을 안 적으면 '품목 입력 필요'와 품목별 목록을 보여 줍니다.
  • 프레논은 제형·용량이 달라도('프레논', '프레논OD', '프레논 50mg') 한 품목으로 봅니다 — 계열 안에 하나라도 불가면 불가.
  • 병원 여부: 병원 품목 매출·영업관리 병원 컨펌 이력이 있거나, 이름·담당 부서·채널에 '병원'이 있으면 병원으로 봅니다. 카드에서 로컬/병원 판정을 바꿔볼 수 있습니다.
  • 확인필요 — 원천에 없는 번호 중 사업자번호 형식 오류이거나 같은 이름 거래처가 따로 있는 경우, 거래처명이 여러 곳과 같거나 정확히 일치하지 않는 경우, 요청 품목명을 찾지 못했거나 요청 품목별 판정이 다른 경우. 사유 칸을 보고 다시 확인해 주세요.
  • 기준 데이터: 영업관리 CSO거래처관리데이터(2주 갱신) + PRM 블럭신청 누계(월 갱신) + CRM 일일보고 진행 블럭(실시간) — 판정 규칙은 2026-10-24 박본님 확정.
