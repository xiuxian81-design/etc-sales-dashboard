#판정요청 거래처사유매칭 거래처
판정 기준
  • 로컬 — 다른 CSO 코드가 이미 생성(마스터·채널매핑 CSO업체) → 불가 / 담당 최두현(오픈블록 이관처) → 가능 / 그 외 현 담당자 있음 → 불가 / 담당 없음(비거래처) → 가능
  • 병원 — 품목별 판정. 기 코드생성 품목 → 불가 / 네트워크 오픈(O) → 가능 / 협의필요(한올·CSO) → 협의필요 / 네트워크 미오픈 → 불가
  • 병원 여부: 네트워크 오픈 목록에 있거나, 채널에 '병원'이 있거나, 병원 품목 매출이 있으면 병원으로 봅니다. 카드에서 로컬/병원 판정을 바꿔볼 수 있습니다.
  • 확인필요 — 원천에 없는 번호 중 사업자번호 형식 오류, 거래처명이 여러 곳과 같거나 이름이 정확히 일치하지 않는 경우(엑셀 일괄). 사업자번호로 다시 확인해 주세요.
  • 원 판정 규칙: 최인경 지부장 'CSO 거래가능 조회'. 기준 데이터: 영업관리 CSO거래처관리데이터(2주 갱신).
